# Widget Pro

## Overview

Widget Pro is a desktop companion app for the fictional Widget workspace. It
adds offline boards, custom keyboard shortcuts and a local search index on top
of the hosted Widget Cloud plan. The app stores its data on the local machine
and synchronises changes when a network connection is available.

## Installation

Download the installer for your operating system from the Widget Cloud portal,
close any running copy of the app, then run the installer. Windows builds ask
for a restart after the first install. macOS builds require dragging the app
into the Applications folder. Linux builds ship as an AppImage that can be made
executable with a single permission change.

## Activation

Sign in with the same account used for Widget Cloud. Activation binds the
desktop app to the workspace and caches a signed licence token for 30 days.
If the app cannot reach the licence service, it keeps working offline for the
remaining cached period and retries in the background. Activation codes are
single use and expire after 14 days if they are never redeemed.

## Licensing

Each licence covers one workspace and up to three devices. Moving a licence to
a new device is allowed twice per year from the workspace settings. Education
workspaces receive the same features without device limits but require annual
re-verification.

## Refund policy

Widget Pro purchases can be refunded within 14 days of the first activation if
the workspace has not used more than one hour of sync time. Refunds are issued
to the original payment method and typically take five business days to appear.
A refund cannot be guaranteed after the 14-day window; support can review
exceptional cases individually.

## Troubleshooting

- The installer reports a signature error: clear the download cache and fetch
  the installer again from the portal.
- The app shows "licence expired": sign out and back in so a fresh token can be
  cached.
- Boards do not sync: confirm the workspace is active and retry from the sync
  status panel.

## System requirements

- Windows 10 or newer, macOS 12 or newer, or a recent 64-bit Linux desktop.
- 4 GB of memory and 500 MB of free disk space.
- A Widget Cloud account on the Standard plan or higher.
